Sistema de Gestión de Prácticas Pedagógicas UBB

Sistema web desarrollado con Spring Boot y Thymeleaf para la supervisión, evaluación y recopilación de evidencias de las prácticas pedagógicas de la Universidad del Bío-Bío.

---

Requisitos del Entorno

- **Java:** 25
- **Maven:** 3.9+ (o utilizar el ejecutable `./mvnw` / `.\mvnw.cmd` del proyecto)
- **Base de Datos:** MySQL 8.4 LTS / MariaDB 10.4.32 (Servidor XAMPP)
- **Navegador:** Cualquier navegador moderno (Chrome, Edge, Firefox)

---

-Crear base de datos: 1) Ejecutar Xampp
